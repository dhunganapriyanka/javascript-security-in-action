Secure JavaScript

This page keeps the same features but uses safer JavaScript and a Content Security Policy (CSP).

Vulnerable JavaScript Secure JavaScript

1. Preventing XSS

This version uses textContent. The input is displayed as text rather than HTML.

Result:

Try the same input: <img src=x onerror="alert('XSS test')">

2. Replacing eval()

This version uses JSON.parse() to read JSON data without running it as JavaScript.

Result:

Try the same unsafe input: {"name": alert("eval test") || "Student"}

The server sends a CSP header that blocks inline JavaScript and use of eval().
